# قوالب — رسائل القروبات

> **خارج حراج فقط.** نشر رابط قروب داخل إعلان حراج سبب حظر
> (`Announcing groups` مذكورة نصاً في صفحة الأسئلة الشائعة).

---

## 1) الرسالة الأساسية

```
السلام عليكم

معلم مباني في الرياض: مشبات، أفران، وجدران.

لو أحد يبي مشبة قبل الشتاء، أو فرن، أو جدار، هذا الإعلان:

[رابط إعلان حراج]

واتساب: 0531060401
```

## 2) نسخة أقصر للحالة


## 3) نسخة المزارع والاستراحات

```

نصل للخرج، والمزاحمية، وثرمداء، ورماح، والحوطة، والدرعية.

أرسل اللوكيشن وصورة المكان: 0531060401
```

## 4) نسخة أهل وجيران الشغل

```
السلام عليكم

لو أحد في الحي يبي مشبة أو فرن قبل البرد، أنا موجود.

أرسل صورة المكان وأعطيك السعر.

0531060401
```

## 5) قواعد النشر

1. **رسالة واحدة كل سبعة أيام لكل موضع.** لا يومياً.
2. **3 مواضع فقط يوم الأربعاء 23** — مواضع يعرفها المعلم أصلاً.
3. **لا تنسخ الرسالة في عشرات القروبات دفعة واحدة.** هذا سبام، ويُبلَّغ عنه، ولا يجلب صاحب مزرعة جاد.
4. **لا تجمع أرقاماً من القروب** ولا تراسل في الخاص بلا سياق.
5. **لا تنشر في قروبات المقاولين والوسطاء.** الجمهور المطلوب هو صاحب الحاجة:
   مزرعة، استراحة، حي، مجلس، أهل.
6. **لا تعلّق على إعلانات المنافسين** بالرابط.
7. **اطلب التفضيل مرة واحدة، ومن شخص حقيقي فقط** — لا من عشوائيين، ولا عبر حسابات منشأة لهذا الغرض.

## 7) رسائل الشركاء والباحثين والطقس

### رسالة شريك (بائع حطب / نقل / طوب حراري / رخام / تجهيز استراحات)

```
السلام عليكم

أنا معلم مباني ومشبات في الرياض.

زباينك اللي يسألون «من يبني مشبة أو فرن؟» رشّحني لهم،

وأنا أرشّحك لكل زبون يسأل عن حطب أو نقل أو خامة.

هذا إعلاني في حراج:

[رابط إعلان حراج]

0531060401
```

### جواب الباحث (لمن يسأل علناً عن معلم أو سعر)

```
السلام عليكم

المشبة البسيطة تبدأ من 1500، والحجم والخامة يغيّران السعر.

لو تبي أبنيها لك بيدي: أرسل صورة المكان وأعطيك سعرك.

0531060401

[الرابط]
```

### زناد الطقس (حالة واتساب عند أول ليلة باردة)

```
الليلة برد في الرياض.

جهّز مشبتك قبل البرد.

0531060401
```

## 8) جدول المواضع — `قروبات.md`

أنشئ الملف عند أول بحث، بهذا الرأس:

```
اسم الموضع | نوع الجمهور (صاحب حاجة / وسيط) | تاريخ النشر | عدد الردود | قرار (يُعاد / لا تُعد)
```

- أي موضع جمهوره **وسيط** ← يُعلَّم `لا تُعد`.
- أي موضع **بلا رد** بعد مضي المدة ← يُوقف.
- الموضع الذي جاء منه سؤال ← يُضاعَف الاهتمام به، ويُسجَّل في تقرير المتابعة (`04`).

**لا تخترع روابط قروبات.** ابحث في مصادر علنية، وسجّل ما تجده فعلاً فقط.
