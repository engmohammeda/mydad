## 5) مسار العميل

```
جديد → سعر مُرسل → موافق → قيد التنفيذ → مسلّم ومدفوع → يوصي
```

**قواعد المسار:**

- الرد الأول خلال **15 دقيقة** في وقت العمل.
- متابعة السعر **مرة واحدة** بعد يوم، ثم توقف.
- لا شغل بلا اتفاق مكتوب على واتساب: نوع الشغل، الحجم، المكان، السعر، وعبارة «موافق» من العميل.
- صورة واحدة للعميل في اليوم أثناء التنفيذ تكفي.
- التسليم والباقي في نفس اللحظة.
- بعد التسليم بيوم: طلب تقييم بجملة واحدة. لا تقييم مزوّر، ولا حساب آخر يكتبه.
  (تذكير: تقييم حراج نفسه يحتاج نحو 5 أيام عمل حتى يظهر.)

## 6) رسائل الخاص

### أول رد

```
أهلاً

عشان السعر يكون على مكانك، لا رقماً عامّاً:

1) مشبة، فرن، جدار، أو فاصل؟

2) الحجم التقريبي؟

3) صورة المكان واللوكيشن؟
```

### بعد يوم، مرة واحدة

```
وصلك السعر؟

أي سؤال عن البنود أنا حاضر.

إذا ناسبك نثبت الاتفاق.
```

### شروط الدفع — خاص، عند الاتفاق فقط، لا في إعلان

```
قبل ما نبدأ، الطريقة عندي واضحة:

السعر المتفق عليه ما يتغير.

دفعة أولى للمواد، والباقي عند التسليم.

إذا ناسبك أرسل «موافق» ونثبت الموعد.
```

**النسبة الداخلية:** **30–50%** قبل شراء الطوب أو الحجر، ولا تُذكر في الصور ولا في الإعلان.
لا يُصرف على المواد أكثر من الدفعة. التسليم = الباقي.
المدة تُكتب في الاتفاق الخاص عندما يعرف المعلم الشغل، ولا تُوعد في الإعلان.

### رفض مشروع كبير

```
تسلم.

أنا أشتغل شغلاً محدداً: مشبات، أفران، جدران، وفواصل.

ما آخذ مشاريع فلل أو عمائر.

بالتوفيق.
```

### بعد التسليم

```
الشغل خلص، وهذه الصور النهائية.

الباقي عند الاستلام، مثل ما اتفقنا.

أي ملاحظة أنا حاضر.
```

### تقييم، بعد يوم

```
عساك مرتاح.

لو كتبت جملة واحدة عن الشغل يفرق معي.
```

### توصية

```
لو تعرف أحد يبي مشبة أو فرن أو جدار، رشّحني له.

وهذا رابط الإعلان لو حاب يفضّله:

[الرابط]
```
